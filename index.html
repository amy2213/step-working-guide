Why this version exists

Built from the source, not from screenshots.

The finished workbook was reconstructed as native digital text and audited against the original source pages. During that audit, condensed and omitted narrative in the earlier browser data was identified and corrected before the final release.

The approved PDF is now the canonical version. The earlier browser prototype has been archived in the repository so it cannot be confused with the source-verified workbook.

Search and select textNo scanned-page layer in the finished workbook.
Write as much as neededAll response fields are multiline with no MaxLen restriction.
Keep answers localThe workbook is designed so responses live in the PDF file the user saves.
Future archival exportAn expanded-answer edition is planned so long responses can be re-typeset into flowing pages.
